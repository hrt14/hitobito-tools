# hitobito Tools

暮らしや学びを少し便利にする、小さなWebツールのポータルです。

## 公開構成

- `hitobito.jp` — hitobito Tools ポータル
- `habitegg.hitobito.jp` — Habit Egg
- `chinese.hitobito.jp` — 中国語瞬間作文
- `drop.hitobito.jp` — 大河の一滴（水循環シミュレーション）

## 開発

```bash
npm install
npm run dev
```

## 確認

```bash
npm run lint
npm run build
```

GitHubの`main`ブランチをVercelへ接続すると、更新のたびに自動で公開されます。
