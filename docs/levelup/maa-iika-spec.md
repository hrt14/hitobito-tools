# LEVEL UP『まあ、いいか。』仕様書

## コンセプト
予定外の出来事に対して「なんで？」「最悪」「こうなるはずだったのに」と現実と綱引きし続ける反応を短くし、「そうなったか」「じゃあ次どうしよう」「まあ、いいか」と事実を受け取って次へ進む反射を鍛える。

勝利条件は、嫌なことが起きないことではない。**予定外が起きた後、操作権を取り戻すまでの時間が短いこと。**

## 学習させる反射
`予定外 → 事実を確定 → 抵抗を終了 → 変えられる部分だけ動かす → 次へ`

「まあ、いいか」は放置・迎合・感情抑圧ではない。変えられない事実との綱引きをやめる合図として使う。変えられる問題では「受け入れて動く」を正解にする。

## 1セッション
- 10ラウンド、2〜4分
- 日常の予定外イベントを1枚ずつ提示
- 4つの内的反応から1つをタップ
- 抵抗/回避を選ぶとストレスが上がるが、出来事は消えずラウンドも進まない
- 受容/受容+行動を選ぶと出来事が流れ、次ラウンドへ進む
- 連続受容で FLOW コンボ
- 終了時に SCORE / 引っかかり秒相当 / 受容率 / ランクを表示

## ゲームの核心
「悪い選択肢は減点される」だけでは弱い。**抵抗を選んでも出来事そのものは変わらず、その場に残り続ける**ことをルールで体験させる。プレイヤーはストレスだけ増えていることに気づき、受容に切り替えた瞬間に初めてゲームが前へ進む。

## 反応タイプ
1. 抵抗: 「なんで？」「最悪」「ありえない」など。ストレス大幅増、進行なし。
2. 回避: 「どうでもいい」「見なかったことにする」など。ストレス小〜中増、進行なし。
3. 受容: 「そうなったか」「残念。でも次へ」。ストレス減、進行。
4. 受容+行動: 請求ミス、提出ミスなど変えられる問題で使用。事実を受け取った上で問い合わせ・訂正などへ進む。

## 難易度
- 初級: 天気、行列、店の休業、電車遅延
- 中級: キャンセル、返信なし、不採用、予定変更
- 上級: 自分のミス、相手の方針変更、誤請求、作業消失

上級では「まあ、いいか = 何もしない」という誤学習を壊し、受容と問題解決を両立させる。

## UI
- スマホ縦持ち中心
- 上部: ROUND / STRESS / FLOW
- 中央: 予定外イベントを大きな1枚カードで表示
- カード周囲: 「なんで？」「最悪」「こうなるはずだったのに」の思考雲
- 下部: 4反応ボタン
- 抵抗時: カードが揺れ、ストレス上昇。イベントは残る
- 受容時: カードが落ち着き、進行ライン上の点が前進

## スコア
- 受容/行動選択: 基礎70点 + 強度ボーナス + FLOWボーナス + 速度ボーナス
- 抵抗: -22点、抵抗カウント増
- 回避: -10点、抵抗カウント増
- ランク S/A/B/C

## コンテンツ方針
最低30イベントまで拡張可能なデータ駆動構造にする。同じ原理を、移動・仕事・人間関係・買い物・旅行・制作など表面の違う場面で反復する。

## 完了条件
- 開始10秒以内に「予定外への反応を選ぶゲーム」と分かる
- 抵抗を押したとき、なぜ進まないか画面だけで分かる
- 受容すると即座に次へ進み、操作が気持ちいい
- 10ラウンドが2〜4分で完了する
- スマホ幅320px以上で横スクロールしない
- 受容と放置を混同させない上級問題が含まれる
- リロードしてもベストランクだけ保持する
