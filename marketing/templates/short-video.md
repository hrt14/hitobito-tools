# ショート動画 台本テンプレート（Shorts / TikTok / Reels 共通）

縦 9:16、15〜40秒。同じ素材を3プラットフォームに出す。

```yaml
series: <registry の marketing.series>
title: <30字以内。動画内の1行目と同じ言葉>
utm_content: <YYYYMMDD-短い名前>
length: <秒>
```

## 構成

| 秒 | 役割 | 書くこと |
| --- | --- | --- |
| 0–2 | フック | 画面の一番おもしろい変化を最初に見せる。テロップ1行（15字以内） |
| 2–10 | 何をするものか | 実際の操作。手元・タップ・画面の反応。説明テロップは1つだけ |
| 10–25 | 変化・結果 | 続けると／遊ぶと何が起きるか。前後比較か、育った状態 |
| 25–終 | 行き先 | 「hitobito の <サービス名>」＋「プロフィールのリンクから」 |

## チェック

- [ ] 最初の2秒で、音なしでも何の動画かわかる
- [ ] 実際のアプリ画面を使っている（モックやイメージ画像で代用していない）
- [ ] 実在の人の名前・私的な内容が画面に映っていない
- [ ] 誇大表現なし（`BRAND.md`「トーン」）
- [ ] 説明欄のリンクに UTM が付いている（`UTM.md`）
- [ ] ハッシュタグ：`#hitobito` ＋ 台帳のシリーズのハッシュタグ
- [ ] YouTube はシリーズの再生リストに追加した

## 説明欄テンプレート

```
<1行でサービスの価値。registry の tagline を基本にする>

▶ <サービス名>: <UTM付きURL>
▶ hitobito のほかのツール・ゲーム: https://hitobito.jp/links?s=<source>

#hitobito #<シリーズのハッシュタグ>
```
