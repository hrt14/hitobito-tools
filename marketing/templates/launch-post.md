# 新サービス公開時の告知セット

`registry/products.json` で `status: "live"` になったサービスだけを告知する。本番URLで実際に動くことを確認してから出す。

## セット内容

1. **YouTube 長尺（1〜3分）**：最初の1分でアプリを実際に使いきる画面収録。残りは作った理由と使いどころ。
2. **ショート 3本**：`short-video.md` の構成で、それぞれ別のフック（見た目／使いどころ／意外な機能）。
3. **X 告知ポスト**：下のテンプレート。画面収録の動画かGIFを添付する。
4. **リンク集**：台帳の `marketing.promote` を `true` にして `hitobito.jp/links` に載せる。

## X 告知テンプレート

```
hitobito から新しい<ツール／ゲーム>を公開しました。

<サービス名>
<tagline>

<使いどころを1行>

<UTM付きURL（utm_source=x）>
#hitobito #<シリーズのハッシュタグ>
```

## 公開後1週間

- 3日後：反応の多かった機能に絞ったショートを1本追加。
- 7日後：UTM 別の流入を確認し、`series/<series>.md` の「振り返り」に書く。
