# hitobito ブランド基本ルール

## 名前の表記

- ブランド名は小文字の **hitobito**（文頭でも大文字にしない）。
- サービス名は `registry/products.json` の `name` をそのまま使う（例: Habit Planet、Habit Egg、LIFE +1、LEVEL UP）。
- 「hitobito の〇〇」と書く。「〇〇 by hitobito」は動画のエンドカードだけで使う。

## 3つの柱（ポータルと同じ言葉を使う）

| 柱 | 一言 | 対象 |
| --- | --- | --- |
| Tools | 使う。 | 暮らし・学び・仕事の小さな道具 |
| Games | 遊ぶ。 | スマホですぐ遊べる、小さくて変な世界 |
| LEVEL UP | 鍛える。 | 思考の癖を反射になるまで鍛えるゲーム |

## 色

ポータル（`app/portal.module.css`）と同じ値を使う。

| 用途 | 色 |
| --- | --- |
| 背景 | `#f4f4ee` |
| 文字 | `#171a15` |
| アクセント（hitobito の緑） | `#9cc600` |
| 補助文字 | `#7a8174` |

サムネイルは「背景の上に、黒の太字で短いコピーを置き、アクセントの緑を1か所だけ使う」を基本にする。サービス固有の色はアプリ画面の中で見せる。

## トーン

- 画面を見せる。説明より、触っている手元と画面の変化を先に見せる。
- 言い切る。短く。「〜できるかもしれません」ではなく「〜できる」。
- 煽らない。「人生が変わる」「絶対」「〇〇しないと損」は使わない。
- 数字を盛らない。ユーザー数・効果などは実測値だけを使う。

## やらないこと

- 実在の個人・顧客・勤務先・私的な出来事を、許可なく例に使わない（`AGENTS.md` と hitobito-games の `docs/PUBLIC_REPO_PRIVACY.md` に従う）。
- 他社サービスのロゴ・画面を無断で使わない。
- 未公開のサービスを「公開中」と表記しない（`status` が `live` のものだけを告知する）。
