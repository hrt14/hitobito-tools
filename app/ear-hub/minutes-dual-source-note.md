# 議事録の音声入力について

Chromeの画面・タブ共有で「音声を共有」を選ぶと、その共有元の音声をPC音声として文字起こしできます。タブ音声やシステム音声の可否はOS・ブラウザ・共有対象によって異なります。共有元を個別に選べるため、他のアプリの音声が含まれるとは限りません。

「自分のマイク」「PCの音声」のラベルは音声入力元です。人物本人を識別する話者分離ではなく、スピーカーから漏れたPC音声をマイクが拾えば重複する場合があります。イヤホン推奨。ブラウザ内蔵音声認識サービスへ音声データが送られる場合があり、議事録要約は文字起こし本文をサーバーAPIへ送信します。会議参加者の同意を得て利用してください。
