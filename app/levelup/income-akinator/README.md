# 年収アキネーター

- User answers only **はい / いいえ**; there is no text input.
- The next occupation question is selected dynamically from the remaining questions based on how well it separates the current top candidates.
- Income is a game-only heuristic derived from the guessed broad occupation plus experience/responsibility answers.
- Do not present the result as public wage statistics or use it for employment, compensation, or hiring decisions.
- Production route: `https://levelup.hitobito.jp/income-akinator`
